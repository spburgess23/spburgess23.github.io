<h1>About</h1>

This site is the delivery layer of a home-grown photogrammetry setup. Photos
go in one end; walkable 3D rooms come out the other and end up here, hosted
as a fully static site on GitHub Pages.

The pipeline does the heavy lifting on the Linux box — meshing, clean-up,
web optimisation — and the website just consumes its output. Adding a new
room to this gallery is a single script run, no code involved.

The rest of the site collects the other projects that happen along the way.
Everything here is static: no backend, no database, no accounts.
